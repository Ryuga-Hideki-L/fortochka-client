## 🔑 ГЛАВНЫЙ ПЕРЕВОРОТ ДИАГНОЗА
«Заморозка по объёму на прямом IP» — **вероятно НЕ про протокол, а про репутацию IP.**
На ОДНОМ OVH-IP висят 6 нестандартных сервисов: Reality×3 порта (40443/46443/47443) + hy2:443 +
tuic:8443 + awg:51833. Это готовая **сигнатура прокси-хоста** для active-probing РКН → весь IP
получает флаг → душится ВЕСЬ трафик к нему, каким бы неотличимым ни был каждый протокол.
Отсюда: мой прошлый фикс (увести Reality/grpc в ручной, авто = UDP+CDN) — **правильный band-aid
на СЕЙЧАС** (при одном спалённом IP UDP/CDN реально надёжнее), но **стратегически** надо
де-сигнатурить IP и вернуть Reality (лучший транспорт 2026, <5% детект) в основные.

## ВОЗМОЖНЫЕ КОСЯКИ (проверенные/вероятные)
1. **6 сервисов на 1 IP** → флаг прокси-хоста. Вероятная корневая причина троттлинга. Разнести по IP.
2. **Reality decoy SNI = `api-maps.yandex.ru`** (RU-домен на FR-IP OVH) — несоответствие SNI↔гео, палится. [ПОДТВЕРЖДЕНО на сервере]
3. **Один dest/SNI на все 3 Reality-порта** — паттерн корреляции. Разные dest на инбаунды.
4. **sslip.io-серт для hy2** — узнаваемый VPN-туториал-паттерн (голый IP + free CA + wildcard-сервис).
5. **OVH дропает фрагментированный UDP на Edge-фаерволе** — возможная причина смертей hy2/tuic у Сергея. [из доков OVH]
6. **~27000 UDP rcvbuf-ошибок** на сервере — дроп UDP на приёме, тюнинг буферов. [ПОДТВЕРЖДЕНО]
7. **Панели (3x-ui/gate) на том же IP** — скан панели (у 3x-ui узнаваемое поведение) тянет репутацию всего IP.
8. **Gcore Free = SPOF доставки** + вероятная L7-фильтрация нашего WS-трафика (Free-тир). Циклическая зависимость.
9. **Нет embedded-fallback в клиенте** — если Gcore+origin разом недоступны, у клиента нет плана Б.
10. Не подтверждено: flow=xtls-rprx-vision + корректный fp на Reality-инбаунде (проверить, не полагаться на дефолт 3x-ui). Xray у нас 26.7.11 — свежий, ок.

## ПРИОРИТИЗИРОВАННЫЙ ПЛАН (дёшево/эффективно → дорого)
1. **(часы, free) Аудит+фикс Reality:** flow=vision, fp=firefox, **сменить decoy на иностранный** (напр. www.microsoft.com), разные dest на инбаунды.
2. **(часы, free) DoH-резолв домена в клиенте** — резолвить vpn.rungvard.net через DoH, а не системный DNS (закрывает DNS-блок вектор, штатная фича sing-box).
3. **(часы, free) UDP-тюнинг сервера** — поднять rmem_default; убедиться что hy2/tuic НЕ фрагментируют (иначе OVH дропает). Проверить размер QUIC-пакета.
4. **(часы, дёшево) Убрать sslip.io** — отдельный домен под hy2 или self-signed+pinned (hy2 умеет нативно, публичный CA не нужен).
5. **(день, free) Embedded fallback-адреса в клиент** — 2-3 emergency-эндпоинта в Go-бинаре; если подписка недоступна N попыток → падать на них.
6. **(день, free) Второй канал доставки** — Telegram-бот на 10 человек / GitHub-raw, не зависит от Gcore.
7. **(дни) Разнести протоколы по IP** — минимум Reality на отдельный IP от UDP-кучи; проверить гипотезу IP-репутации; вернуть Reality в auto-pool.
8. **(дни-неделя) Port-hopping для Hysteria2** — диапазон UDP-портов + iptables DNAT на сервере, hop в клиенте (sing-box умеет). Спасает от per-port UDP-throttle (Сергей).
9. **(неделя, $) Второй CDN** — CloudFront (ещё держит fronting; Fastly запретила, Cloudflare троттлит 16КБ) параллельно Gcore, 2 домена в подписке → реальный межCDN failover.
10. **(недели, $/мес) Второй VPS на другом провайдере/ASN** — реальный второй сетевой путь (не CDN-обёртка вокруг того же origin).
11. **(низкий приоритет) TLS-fragment** только на WS+CDN пути (НЕ на Reality — там навредит). ECH — только если Gcore поддержит (не подтверждено). **WARP — НЕ делать** (фактура: заблокирован в РФ 2026).

## ВКЛАДКА «РАЗМОРОЗКА БЕЗ VPN» (Zapret/DPI-десинк) — рекомендация
Задача: локально расшить замедление YouTube/Discord/доменов **без туннеля**.
**Брать ByeDPI** (github.com/hufrea/byedpi, v0.17.3, активен):
- **User-space SOCKS5-прокси, БЕЗ драйвера, БЕЗ админ-прав, НЕ палится антивирусами** (в отличие от Zapret2/GoodbyeDPI — тем нужен WinDivert.sys: драйвер, админ, флаги AV, BSOD с ESET).
- **НЕ конфликтует с VPN-TUN** (sing-box) — можно держать обе вкладки: DPI-десинк для YouTube + VPN для заблокированного. WinDivert-варианты конфликтуют с TUN.
- Бандл ~2-3 МБ. Запуск: `byedpi.exe -l 127.0.0.1 -p 1080 --auto --fake-tls --split --disorder`, приложение выставляет системный/браузерный SOCKS 127.0.0.1:1080.
- Списки хостов обновлять (ТСПУ меняется ~ежемесячно).
- Zapret2 (kernel-level, эффективнее) — как опциональный «мощный режим» позже, но для интеграции ByeDPI чище.
Комбо: DPI-десинк (ByeDPI) для РФ-сайтов/замедления + VPN для IP-blocked — стандартная схема, покрывает ~90% кейсов РФ.
